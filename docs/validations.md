# Validations Sabbat

Interface dédiée à la validation et à la clôture des activités hebdomadaires.

## 📋 Fonctionnalités
- **Check-list de validation** : Permet de s'assurer que toutes les données du Sabbat ont été correctement saisies.
- **Workflow de clôture** : Passage au statut "Validé" pour figer les données financières.

## 🛠 Détails Techniques
- **Composant** : `SabbatValidation`.
- **Logique Métier** : Interagit avec les états financiers pour garantir l'intégrité des données avant clôture.
