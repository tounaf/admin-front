# Gestion des Dépenses

Module dédié au suivi des sorties d'argent au sein des établissements.

## 📋 Fonctionnalités
- **Suivi par catégorie** : Visualisation des dépenses selon leur nature.
- **Lien avec les établissements** : Chaque dépense est rattachée à une Fiangonana.
- **Reporting** : Graphiques intégrés pour l'analyse des coûts.

## 🛠 Détails Techniques
- **Composant** : `Expense` et `ExpenseChart`.
- **Intégration** : Le composant `ExpenseChart` est réutilisé dans le Dashboard pour une vue synthétique.
